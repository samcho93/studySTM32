L13DC 모터 드라이버

L298N의 IN1·IN2·ENA로 방향과 PWM 속도를 제어하고, 가변저항·버튼으로 속도와 방향을 바꿉니다.

선수 레슨: L08 L09
시뮬레이터에서 실습

학습 목표#

  • MCU 핀으로 모터를 직접 돌리면 안 되는 이유와 H-브리지 드라이버의 원리를 설명합니다.
  • L298N 모듈의 IN1 · IN2(방향) 와 ENA(PWM 속도) 로 정방향 · 역방향 · 정지를 제어합니다.
  • 모터용 PWM 주파수를 고르고(PSC · ARR), 방향과 속도를 합친 motor_set(-999 ~ +999) 함수를 씁니다.
  • 가변저항으로 속도, 버튼 인터럽트로 방향을 바꾸는 프로그램을 만듭니다.

왜 드라이버가 필요한가#

작은 DC 모터도 수백 mA ~ 수 A 를 흘리고, 멈출 때는 코일에서 역기전력(전압 스파이크)이 생깁니다. STM32 핀은 수 mA ~ 20 mA 밖에 못 내고 3.3 V 이므로 모터를 직접 연결하면 핀이 망가집니다. 모터는 별도 전원 + 드라이버로 돌리고, MCU 는 드라이버에 논리 신호만 줍니다.

H-브리지는 스위치 4개를 H 모양으로 배치해, 대각선 두 개를 켜는 방향에 따라 모터에 흐르는 전류 방향(= 회전 방향)을 바꿉니다. L298N 은 H-브리지 두 개(모터 A, B)가 든 칩이고, 흔히 쓰는 빨간 모듈에는 5 V 레귤레이터와 방열판이 붙어 있습니다.

PWM 을 ENA 에 넣으면 H 인 동안만 전원이 걸려 평균 전압이 듀티비에 비례합니다.

PWM 주파수#

1 kHz 같은 낮은 주파수로 모터를 돌리면 코일이 떨며 "삐-" 소리가 납니다. 사람 귀에 들리지 않는 20 kHz 근처를 많이 씁니다.

  • 84 MHz / (PSC 3 + 1) / (ARR 999 + 1) = 21 kHz, 듀티 범위 0 ~ 999

CubeMX: PA6 → TIM3_CH1, TIM3 Channel1 PWM Generation CH1, Prescaler 3, Counter Period 999, Pulse 0.

L298N 은 전압을 먹습니다

L298N 은 오래된 바이폴라 트랜지스터 구조라 출력에서 약 2 V(최대 수 V) 가 빠집니다. 6 V 모터를 6 V 전원으로 돌리면 약 4 V 만 걸립니다. 효율이 중요한 작품에는 TB6612FNG, DRV8833 같은 MOSFET 드라이버가 더 좋습니다. 제어 방법(IN1/IN2 + PWM)은 거의 같습니다.

motor_set 함수#

방향과 속도를 부호 있는 정수 하나로 다루면 코드가 깔끔해집니다. 양수 = 정방향, 음수 = 역방향, 0 = 정지.

cCore/Src/main.c
/* USER CODE BEGIN 0 */
/* speed: -999 ~ +999. 부호가 방향, 크기가 PWM 듀티(ARR=999 기준)입니다. */
void motor_set(int speed)
{
  if (speed > 999) speed = 999;
  if (speed < -999) speed = -999;

  if (speed > 0) {                 // 정방향: IN1=1, IN2=0
    HAL_GPIO_WritePin(MOTOR_IN1_GPIO_Port, MOTOR_IN1_Pin, GPIO_PIN_SET);
    HAL_GPIO_WritePin(MOTOR_IN2_GPIO_Port, MOTOR_IN2_Pin, GPIO_PIN_RESET);
  } else if (speed < 0) {          // 역방향: IN1=0, IN2=1
    HAL_GPIO_WritePin(MOTOR_IN1_GPIO_Port, MOTOR_IN1_Pin, GPIO_PIN_RESET);
    HAL_GPIO_WritePin(MOTOR_IN2_GPIO_Port, MOTOR_IN2_Pin, GPIO_PIN_SET);
    speed = -speed;
  } else {                         // 정지: EN=0 이면 자유 회전으로 멈춤
    HAL_GPIO_WritePin(MOTOR_IN1_GPIO_Port, MOTOR_IN1_Pin, GPIO_PIN_RESET);
    HAL_GPIO_WritePin(MOTOR_IN2_GPIO_Port, MOTOR_IN2_Pin, GPIO_PIN_RESET);
  }
  __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, speed);   // ENA 에 PWM
}
/* USER CODE END 0 */

예제 1 — 정방향 · 정지 · 역방향#

시뮬레이터에서 열기모터 기본 동작 열기새 창l13-motor-basic
cCore/Src/main.c
  /* USER CODE BEGIN 2 */
  HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
  /* USER CODE END 2 */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    motor_set(600);    // 정방향 60 %
    HAL_Delay(2000);
    motor_set(0);      // 정지
    HAL_Delay(1000);
    motor_set(-999);   // 역방향 100 %
    HAL_Delay(2000);
    motor_set(0);
    HAL_Delay(1000);
  }
  /* USER CODE END 3 */

시뮬레이터의 모터 노드는 ENA 듀티와 IN1/IN2 에 따라 회전 방향과 속도(최대 maxRpm)를 보여 줍니다. 실물 모터는 듀티가 너무 낮으면(보통 20~30 % 이하) 마찰을 이기지 못해 돌지 않고 윙 소리만 납니다.

예제 2 — 가변저항 속도 + 버튼 방향#

가변저항(PA0, ADC1_IN0)으로 속도를, B1(EXTI)으로 방향을 바꿉니다. 상태는 1초에 두 번 UART 로 기록합니다.

시뮬레이터에서 열기가변저항 + 버튼 모터 열기새 창l13-motor
cCore/Src/main.c
/* USER CODE BEGIN PV */
volatile int dir = 1;              // +1 정방향, -1 역방향 (버튼 인터럽트가 바꿈)
volatile uint32_t last_press = 0;
int last_dir = 1;
uint32_t last_print = 0;
/* USER CODE END PV */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    int speed = (int)(read_pot() * 999 / 4095);
    if (speed < 50) speed = 0;          // 데드존: 끝까지 내리면 확실히 정지

    if (dir != last_dir) {              // 방향이 바뀌면 먼저 멈췄다가
      motor_set(0);
      HAL_Delay(300);
      last_dir = dir;
    }
    motor_set(dir * speed);

    if (HAL_GetTick() - last_print >= 500) {
      last_print = HAL_GetTick();
      printf("dir=%s  duty=%d%%\r\n", dir > 0 ? "CW " : "CCW", speed * 100 / 999);
    }
    HAL_Delay(20);
  }
  /* USER CODE END 3 */

/* USER CODE BEGIN 4 */
/* printf 리타깃: syscalls.c 의 _write() 가 글자마다 이 함수를 부릅니다. */
int __io_putchar(int ch)
{
  HAL_UART_Transmit(&huart2, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
  return ch;
}

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
  if (GPIO_Pin == B1_Pin && HAL_GetTick() - last_press > 200) {
    last_press = HAL_GetTick();
    dir = -dir;
  }
}
/* USER CODE END 4 */
  • 데드존 — 가변저항을 끝까지 내려도 ADC 값이 0 이 아닐 수 있으니, 50 미만은 0 으로 처리해 확실히 멈춥니다.
  • 방향 전환 전 정지 — 돌던 모터를 곧바로 반대로 돌리면 큰 전류가 흐르고 기구에 충격이 갑니다. 300 ms 멈췄다가 바꿉니다.
  • dir 은 인터럽트에서 바뀌므로 volatile, 메인 루프는 last_dir 과 비교해 변화를 감지합니다.
모터는 반드시 별도 전원

모터를 켜는 순간 전류가 크게 흘러 전원 전압이 떨어지면 STM32 가 리셋됩니다(브라운아웃). 모터 전원은 배터리나 어댑터로 따로 공급하고, GND 만 보드와 공통으로 묶으세요. 전원 단자 근처에 100 µF 전해 콘덴서를 달면 도움이 됩니다.

실습
  1. 예제 1의 속도를 200 / 400 / 600 / 800 / 999 로 차례로 올리는 소프트 스타트로 바꾸세요(단계마다 300 ms).
  2. motor_set(0) 을 급정지(IN1 = IN2 = HIGH, ENA = 999)로 바꾸는 motor_brake() 를 만들고 자유 정지와 비교하세요.
  3. 예제 2에서 방향 전환 때 300 ms 동안 속도를 서서히 0으로 줄였다가 반대 방향으로 올리도록 바꾸세요.
스스로 확인
  • IN1 = L, IN2 = H, ENA 듀티 50 % 일 때 모터는?
  • 모터 PWM 을 21 kHz 로 할 때 72 MHz 보드에서는 PSC · ARR 를 어떻게 잡나요?

자주 나는 오류와 해결#

증상원인해결
모터가 전혀 안 돔GND 공통 안 됨, ENA 점퍼·배선, HAL_TIM_PWM_Start 누락, 모터 전원 없음GND 연결, PWM 시작, 전원 확인
한쪽 방향으로만 돔IN2 핀 미연결 또는 라벨 오류배선·라벨 확인
낮은 속도에서 윙 소리만 나고 안 돔듀티가 기동 토크보다 낮음최소 듀티(예: 250) 설정, 데드존
모터를 켜면 보드가 리셋됨전원 공유로 전압 강하, 역기전력 노이즈모터 전원 분리, 콘덴서, 배선 꼬기
모터에서 삐 소리PWM 주파수가 가청 대역PSC/ARR 로 20 kHz 근처로
속도가 최고에서 더 안 올라감L298N 전압 강하전원 전압 확인, MOSFET 드라이버 고려
