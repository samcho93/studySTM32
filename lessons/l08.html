L08PWM — LED 밝기와 서보

PWM 주파수·듀티를 PSC·ARR·CCR로 정하고, LED 페이드와 50 Hz 서보 각도 제어를 구현합니다.

선수 레슨: L07
시뮬레이터에서 실습HAL 레퍼런스

학습 목표#

  • PWM 의 주파수와 듀티비를 설명하고, 타이머의 PSC · ARR · CCR 로 두 값을 정합니다.
  • CubeMX 에서 타이머 채널을 PWM Generation 으로 설정하고 HAL_TIM_PWM_Start · __HAL_TIM_SET_COMPARE 로 출력합니다.
  • LED 밝기를 부드럽게 바꾸고(페이드), 50 Hz 서보 모터의 각도를 펄스 폭으로 제어합니다.

PWM 이란#

PWM(Pulse Width Modulation)은 디지털 핀을 아주 빠르게 켰다 껐다 하면서 켜져 있는 시간의 비율(듀티비) 을 바꾸는 방법입니다. LED 는 사람 눈이 따라가지 못하는 속도(수백 Hz 이상)로 깜빡이면 평균 밝기로 보이고, 모터는 평균 전압에 해당하는 속도로 돕니다.

듀티 75 %   ▔▔▔▔▔▔▔▔╲_____▔▔▔▔▔▔▔▔╲_____     평균 ≈ 2.5 V

타이머로 PWM 만들기#

PWM 모드 1 에서 타이머 채널은 CNT < CCR 인 동안 HIGH, 나머지 LOW 를 출력합니다. 그래서

  • 주파수 = 타이머 클럭 / ((PSC + 1) × (ARR + 1)) — L07 과 같은 공식
  • 듀티비 = CCR / (ARR + 1) — CCR 은 CubeMX 의 Pulse 값, 코드에서는 __HAL_TIM_SET_COMPARE 로 바꿈
용도타이머 클럭PSCARR주파수CCR 범위
LED 밝기84 MHz839991 kHz0(꺼짐) ~ 999(거의 100 %)
서보 (SG90)84 MHz831999950 Hz (20 ms)500 ~ 2500 = 0.5 ~ 2.5 ms
DC 모터 (L13)84 MHz399921 kHz0 ~ 999

PSC = 83 으로 두면 카운터 1틱이 1 µs 라서 서보처럼 "펄스 폭 몇 µs" 로 말하는 장치를 다루기 편합니다. CCR 을 ARR+1 이상으로 두면 계속 HIGH(100 %), 0 이면 계속 LOW 입니다.

핀과 채널#

타이머 채널은 정해진 핀으로만 나갑니다(대체 기능 AF). NUCLEO-F411RE 에서 자주 쓰는 조합입니다.

핀신호Nucleo 헤더비고
PA0TIM2_CH1A0서보 예제
PA5TIM2_CH1D13LD2 와 같은 핀 — 보드 LED 밝기 조절 가능
PA6TIM3_CH1D12LED 페이드 예제
PA7TIM3_CH2D11
PB6TIM4_CH1D10

CubeMX 설정 (TIM3 CH1, 1 kHz)#

  1. PA6 을 눌러 TIM3_CH1 선택
  2. TIM3 → Channel1: PWM Generation CH1
  3. Prescaler 83, Counter Period 999, PWM Generation Channel 1 → Mode PWM mode 1, **Pulse 0**, Polarity High

예제 1 — LED 페이드#

시뮬레이터에서 열기LED 페이드 열기새 창l08-pwm-led
cCore/Src/main.c
/* USER CODE BEGIN PV */
int duty = 0;      // 0 ~ 999 (ARR)
int step = 10;     // 한 번에 바뀌는 양 (+ 밝아짐, - 어두워짐)
/* USER CODE END PV */

  /* USER CODE BEGIN 2 */
  HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);   // PWM 출력 시작 (이걸 빼면 핀이 움직이지 않습니다)
  /* USER CODE END 2 */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty);
    duty += step;
    if (duty >= 999) {
      duty = 999;
      step = -step;
    } else if (duty <= 0) {
      duty = 0;
      step = -step;
    }
    HAL_Delay(10);
  }
  /* USER CODE END 3 */
  • HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1) 을 빼먹으면 설정은 되어 있어도 핀이 전혀 움직이지 않습니다. 가장 흔한 실수입니다.
  • 10 ms 마다 듀티를 10 씩 바꾸므로 0 → 999 까지 약 1초, 다시 0 까지 1초 걸립니다.
  • 예제 회로에는 로직 분석기 노드(ch0)가 같은 핀에 연결되어 있어, 실습 결과 영역에서 파형의 폭이 변하는 것을 볼 수 있습니다.
사람 눈은 밝기를 로그로 느낍니다

듀티를 일정하게 올려도 어두운 쪽에서 밝기 변화가 크고, 밝은 쪽에서는 거의 변화가 없어 보입니다. 자연스러운 페이드를 원하면 듀티를 제곱으로 바꾸는 감마 보정(예: ccr = duty * duty / 999)을 써 보세요.

예제 2 — 서보 모터 스윕#

취미용 서보(SG90 등)는 20 ms(50 Hz) 마다 들어오는 펄스의 폭으로 각도를 정합니다. 표준은 1 ms(0°) ~ 2 ms(180°) 이지만, SG90 계열은 대략 0.5 ms ~ 2.5 ms 에서 0° ~ 180° 로 움직이는 경우가 많습니다. 제품마다 다르니 양 끝은 조금씩 넓혀 가며 확인하세요.

핀신호서보 선
PA0TIM2_CH1 (PSC 83, ARR 19999, Pulse 1500)신호(주황/노랑)
—5 V 전원빨강
—GND (보드 GND 와 공통)갈색/검정
시뮬레이터에서 열기서보 스윕 열기새 창l08-servo
cCore/Src/main.c
/* USER CODE BEGIN 0 */
/* 0~180도 -> 500~2500 us. 타이머 1틱 = 1 us 이므로 펄스 폭(us)을 그대로 CCR 에 씁니다. */
void servo_write(uint8_t angle)
{
  if (angle > 180) angle = 180;
  uint32_t pulse = 500 + (uint32_t)angle * 2000 / 180;
  __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, pulse);
}
/* USER CODE END 0 */

  /* USER CODE BEGIN 2 */
  HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);
  /* USER CODE END 2 */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    for (int a = 0; a <= 180; a += 10) {
      servo_write(a);
      HAL_Delay(100);
    }
    for (int a = 180; a >= 0; a -= 10) {
      servo_write(a);
      HAL_Delay(100);
    }
  }
  /* USER CODE END 3 */

servo_write() 는 각도를 500 + 각도 × 2000 / 180 µs 로 바꿉니다. 먼저 (uint32_t)angle * 2000 을 계산한 뒤 나누어, 정수 나눗셈에서 정밀도를 잃지 않게 했습니다. 시뮬레이터의 서보 노드는 minUs/maxUs 속성(500/2500)으로 같은 대응을 합니다.

서보 전원은 따로

서보는 움직이는 순간 수백 mA 를 끌어 씁니다. 실물에서 Nucleo 의 5V 핀으로 여러 개를 돌리면 전압이 떨어져 보드가 리셋될 수 있습니다. 별도 5 V 전원을 쓰고, 그 전원의 GND 를 보드 GND 와 반드시 연결하세요(신호의 기준점).

과제#

  1. RGB LED(공통 캐소드)를 TIM3 CH1~CH3 (PA6, PA7, PB0)에 연결하고 무지개색이 순서대로 바뀌게 하세요. PB0 은 TIM3_CH3 입니다.
  2. 가변저항(L09)으로 서보 각도를 조절하는 프로그램을 설계해 보세요(ADC 는 다음 레슨).
  3. 같은 PWM 을 72 MHz 보드(F103)에서 만들려면 PSC 를 얼마로 바꿔야 하나요? 1 kHz LED 용과 50 Hz 서보용 모두 계산하세요.
