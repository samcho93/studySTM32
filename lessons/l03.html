L03GPIO 출력 — LED

GPIO 출력 모드, HAL_GPIO_WritePin·TogglePin, 핀 라벨과 main.h 매크로, BSRR 레지스터 직접 쓰기까지 LED로 익힙니다.

선수 레슨: L02
시뮬레이터에서 실습HAL 레퍼런스

학습 목표#

  • GPIO 포트·핀 번호 체계와 출력 모드(푸시풀·오픈드레인), 출력 속도, 초기 레벨 설정을 이해합니다.
  • HAL_GPIO_WritePin · HAL_GPIO_TogglePin 으로 LED를 켜고 끄고, 핀 라벨 매크로를 활용합니다.
  • 외부 LED를 전류 제한 저항과 함께 올바르게 연결하고, active-high / active-low 를 구분합니다.
  • ODR · BSRR 레지스터로 같은 일을 하고, BSRR이 왜 안전한지 설명할 수 있습니다.

GPIO 기초#

STM32의 범용 입출력 핀은 포트(A, B, C …) × 번호(0~15) 로 부릅니다. PA5 는 포트 A의 5번 핀입니다. 포트마다 16개의 핀과 한 벌의 레지스터(GPIOA->MODER, ->ODR, ->IDR, ->BSRR …)가 있습니다.

모드용도CubeMX 이름
입력버튼, 디지털 센서 읽기GPIO_Input
출력LED, 릴레이 모듈, 칩 선택(CS) 신호GPIO_Output
대체 기능(AF)UART·SPI·I2C·타이머 같은 주변장치가 핀을 직접 구동USART2_TX, TIM3_CH1 …
아날로그ADC 입력, 전력 절약GPIO_Analog, ADC1_IN0 …

출력 설정 항목 (CubeMX → GPIO)#

항목선택지설명
GPIO output levelLow / HighMX_GPIO_Init() 이 끝났을 때의 초기 출력값
GPIO modeOutput Push Pull / Output Open Drain푸시풀은 HIGH·LOW를 모두 능동 구동. 오픈드레인은 LOW만 끌어내림(I2C, 레벨이 다른 회로)
GPIO Pull-up/Pull-downNo pull-up and no pull-down / Pull-up / Pull-down출력에서는 보통 없음
Maximum output speedLow / Medium / High / Very High에지가 얼마나 가파른지. LED는 Low면 충분(노이즈·EMI가 적음)
User Label예: LD2, LED_REDmain.h 에 LED_RED_Pin, LED_RED_GPIO_Port 매크로 생성

CubeMX가 생성하는 MX_GPIO_Init() 의 핵심은 다음과 같습니다. HAL_GPIO_Init() 에 구조체를 채워 넘기는 방식입니다.

cCore/Src/main.c (생성 코드)
static void MX_GPIO_Init(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};

  __HAL_RCC_GPIOA_CLK_ENABLE();                                  // 포트 A 클럭 켜기

  HAL_GPIO_WritePin(LD2_GPIO_Port, LD2_Pin, GPIO_PIN_RESET);     // 초기 출력 레벨

  GPIO_InitStruct.Pin = LD2_Pin;
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;                    // 푸시풀 출력
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(LD2_GPIO_Port, &GPIO_InitStruct);
}
클럭을 먼저 켜야 합니다

STM32는 전력을 아끼려고 주변장치 클럭이 기본으로 꺼져 있습니다. __HAL_RCC_GPIOA_CLK_ENABLE() 없이 GPIOA 레지스터에 쓰면 아무 일도 일어나지 않습니다. CubeMX가 생성 코드에 넣어 주므로, 직접 초기화 코드를 쓸 때만 신경 쓰면 됩니다.

HAL 함수#

c
void HAL_GPIO_WritePin(GPIO_TypeDef *GPIOx, uint16_t GPIO_Pin, GPIO_PinState PinState);
void HAL_GPIO_TogglePin(GPIO_TypeDef *GPIOx, uint16_t GPIO_Pin);
  • GPIOx — 포트 (GPIOA, GPIOB …) 또는 라벨 매크로 LD2_GPIO_Port
  • GPIO_Pin — 핀 비트 (GPIO_PIN_0 ~ GPIO_PIN_15, 값은 1 << n). GPIO_PIN_6 | GPIO_PIN_7 처럼 여러 핀을 한 번에 줄 수 있습니다.
  • PinState — GPIO_PIN_SET(HIGH, 1) / GPIO_PIN_RESET(LOW, 0)

예제 1 — LD2 깜빡이기#

가장 짧은 STM32 프로그램입니다. TogglePin 은 현재 출력을 반대로 바꿉니다.

시뮬레이터에서 열기LD2 깜빡이기새 창l03-blink
cCore/Src/main.c
  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin);
    HAL_Delay(500);
  }
  /* USER CODE END 3 */

HAL_Delay(ms) 는 1 ms마다 증가하는 SysTick 카운터(HAL_GetTick())가 지정 시간만큼 지날 때까지 기다리는(블로킹) 함수입니다. 기다리는 동안 CPU는 다른 일을 못 합니다. 여러 일을 동시에 하는 방법은 L06(HAL_GetTick 비교)과 L07(타이머 인터럽트)에서 배웁니다.

예제 2 — 외부 LED 신호등#

외부 LED 세 개를 연결해 신호등을 만듭니다.

핀라벨연결Nucleo 헤더
PA6LED_RED빨강 LED 애노드(+) → 저항 → GNDD12
PA7LED_YELLOW노랑 LEDD11
PA8LED_GREEN초록 LEDD7
시뮬레이터에서 열기신호등 열기새 창l03-traffic
cCore/Src/main.c
/* USER CODE BEGIN 0 */
/* 세 LED 를 한 번에 설정합니다. 인자가 0 이 아니면 켭니다. */
void set_lights(uint8_t red, uint8_t yellow, uint8_t green)
{
  HAL_GPIO_WritePin(LED_RED_GPIO_Port, LED_RED_Pin, red ? GPIO_PIN_SET : GPIO_PIN_RESET);
  HAL_GPIO_WritePin(LED_YELLOW_GPIO_Port, LED_YELLOW_Pin, yellow ? GPIO_PIN_SET : GPIO_PIN_RESET);
  HAL_GPIO_WritePin(LED_GREEN_GPIO_Port, LED_GREEN_Pin, green ? GPIO_PIN_SET : GPIO_PIN_RESET);
}
/* USER CODE END 0 */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    set_lights(0, 0, 1);   // 초록 3초
    HAL_Delay(3000);
    set_lights(0, 1, 0);   // 노랑 1초
    HAL_Delay(1000);
    set_lights(1, 0, 0);   // 빨강 3초
    HAL_Delay(3000);
  }
  /* USER CODE END 3 */

세 핀을 한 번에 다루는 set_lights() 함수를 USER CODE BEGIN 0 에 정의했습니다. main 보다 위에 있으므로 따로 원형(PFP)이 필요 없습니다. 인자 red ? GPIO_PIN_SET : GPIO_PIN_RESET 은 0이 아니면 SET, 0이면 RESET 을 고르는 삼항 연산자입니다.

LED 배선과 전류 제한 저항#

LED는 켜지는 순간 전압이 거의 일정(빨강 약 2.0 V, 파랑·흰색 약 3.0 V)하기 때문에, 저항 없이 연결하면 전류가 제한되지 않습니다. 3.3 V 핀에서 빨강 LED에 약 5 mA 를 흘리려면

R = (3.3 - 2.0) / 0.005 ≈ 260 Ω

이므로 220~330 Ω 저항을 씁니다. STM32 핀 하나가 안전하게 내보낼 수 있는 전류는 수 mA ~ 20 mA 정도이고, 칩 전체의 합계 한도도 있습니다(데이터시트의 Absolute maximum ratings 확인).

연결 방식회로켜는 값
active-high핀 → 저항 → LED → GNDGPIO_PIN_SET 에서 켜짐
active-low3.3V → 저항 → LED → 핀GPIO_PIN_RESET 에서 켜짐 (BluePill 의 PC13 LED)

시뮬레이터의 LED 노드는 Properties 의 active 속성으로 두 방식을 모두 흉내 냅니다.

레지스터로 직접 쓰기 — ODR 과 BSRR#

HAL 함수는 결국 GPIO 레지스터에 값을 씁니다. 두 레지스터를 알아 두면 HAL 코드가 무엇을 하는지 보입니다.

레지스터비트동작
GPIOx->ODR0~15출력 데이터. 읽고 쓸 수 있음. ODR ^= (1 << 5) 로 반전
GPIOx->IDR0~15입력 데이터(읽기 전용). 핀의 실제 전압 레벨
GPIOx->BSRR0~15 (BS)1을 쓴 핀을 HIGH로 (0을 쓴 비트는 영향 없음)
GPIOx->BSRR16~31 (BR)1을 쓴 핀을 LOW로
GPIOx->BRR0~151을 쓴 핀을 LOW로 (F1 등 일부 제품군에만 있음)
시뮬레이터에서 열기BSRR로 깜빡이기새 창l03-bsrr
cCore/Src/main.c
  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    GPIOA->BSRR = GPIO_PIN_5;                    // 하위 16비트: 1 을 쓴 핀을 HIGH
    HAL_Delay(500);
    GPIOA->BSRR = (uint32_t)GPIO_PIN_5 << 16;    // 상위 16비트: 1 을 쓴 핀을 LOW
    HAL_Delay(500);
  }
  /* USER CODE END 3 */

ODR 로 한 핀만 바꾸려면 읽고 → 비트 수정하고 → 다시 쓰는 세 단계가 필요합니다. 그 사이에 인터럽트가 같은 포트의 다른 핀을 바꾸면 그 변경이 덮어써질 수 있습니다. BSRR 은 쓰기 한 번으로 원하는 핀만 바꾸므로 이런 문제가 없습니다(원자적 동작). 실제로 HAL_GPIO_WritePin() 도 내부에서 BSRR 을 씁니다.

실습
  1. 신호등 예제에 노랑 점멸 모드를 추가하세요: 초록 → 노랑 → 빨강 순서를 3번 돈 뒤, 노랑만 0.5초 간격으로 5번 깜빡입니다.
  2. Properties 에서 초록 LED 노드의 active 를 low 로 바꾸고 결과를 관찰하세요. 코드를 어떻게 고쳐야 원래대로 동작할까요?
  3. BSRR 예제를 GPIOA->ODR ^= GPIO_PIN_5; 한 줄 + HAL_Delay(500); 으로 바꿔도 같은지 확인하세요.
스스로 확인
  • GPIO_PIN_6 | GPIO_PIN_7 의 값은 몇인가요? 이 값을 WritePin 에 넘기면 무슨 일이 일어나나요?
  • 3.3 V 핀으로 파란 LED(순방향 3.0 V)에 5 mA 를 흘리려면 저항이 얼마여야 하나요?

자주 나는 오류와 해결#

증상·메시지원인해결
외부 LED가 전혀 안 켜짐LED 극성 반대(긴 다리가 +), 핀을 출력으로 설정하지 않음, 회로 노드 선 미연결극성 확인, 핀아웃에서 GPIO_Output, 회로 노드 탭에서 선 확인
LED가 켜져야 할 때 꺼지고 반대로 동작active-low 배선인데 SET 으로 켬배선 방식에 맞춰 SET/RESET 바꾸기
'LED_RED_Pin' undeclared라벨 오타 또는 다시 생성하지 않음핀아웃의 라벨과 코드 이름을 똑같이
LED가 아주 어둡게 켜짐저항이 너무 큼(수 kΩ 이상) 또는 핀을 입력으로 둠(내부 풀업 전류만 흐름)220~330 Ω, 모드 확인
실물에서 보드가 리셋되거나 뜨거워짐저항 없이 연결, 핀 합계 전류 초과즉시 전원 분리 후 저항 추가. 큰 부하는 트랜지스터·드라이버로

과제#

  1. LED 네 개로 2비트 이진 카운터 두 개(0~3 반복, 서로 다른 속도)를 만드세요. HAL_Delay 하나로 두 속도를 만들 방법을 생각해 보세요.
  2. HAL_GPIO_WritePin 을 쓰지 않고 BSRR 만으로 신호등 예제를 다시 쓰세요.
  3. 푸시풀과 오픈드레인 출력의 차이를 그림으로 설명하고, 오픈드레인이 필요한 경우 두 가지를 조사하세요.
