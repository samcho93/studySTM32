L127세그먼트 FND

공통 캐소드·애노드와 세그먼트 패턴 표를 만들고, HAL과 BSRR 레지스터 두 방식으로 숫자를 표시합니다.

선수 레슨: L05
시뮬레이터에서 실습

학습 목표#

  • 7세그먼트 표시기(FND)의 세그먼트 이름(a~g, dp)과 공통 캐소드 / 공통 애노드 구조를 설명합니다.
  • 숫자 0~9 의 세그먼트 패턴 표를 직접 만들고, 비트 연산으로 핀에 출력합니다.
  • 같은 표시를 HAL_GPIO_WritePin 반복과 **GPIOC->BSRR 한 번 쓰기** 두 방식으로 구현하고 차이를 설명합니다.

7세그먼트 구조#

FND 는 LED 8개(획 7개 + 소수점)를 숫자 모양으로 배치한 부품입니다. 각 LED 를 세그먼트라 부르고 a ~ g, dp 로 이름 붙입니다.

text
      ─a─
    │     │
    f     b
    │     │
      ─g─
    │     │
    e     c
    │     │
      ─d─    ● dp
종류공통 핀세그먼트를 켜려면
공통 캐소드 (CC)모든 LED 의 캐소드(−)가 GND 로세그먼트 핀을 HIGH
공통 애노드 (CA)모든 LED 의 애노드(+)가 3.3V/5V 로세그먼트 핀을 LOW

세그먼트마다 LED 이므로 세그먼트마다 저항(220~470 Ω)을 하나씩 달아야 합니다. 공통 핀에 저항 하나만 달면 켜진 세그먼트 수에 따라 밝기가 달라집니다.

핀 배치와 패턴 표#

세그먼트 a ~ dp 를 PC0 ~ PC7 에 차례로 연결합니다. 이렇게 한 포트의 연속된 비트에 두면 패턴 바이트를 그대로 포트에 쓸 수 있습니다.

핀라벨세그먼트비트
PC0SEG_Aabit0
PC1SEG_Bbbit1
PC2SEG_Ccbit2
PC3SEG_Ddbit3
PC4SEG_Eebit4
PC5SEG_Ffbit5
PC6SEG_Ggbit6
PC7SEG_DPdpbit7

숫자마다 켜야 할 세그먼트를 비트로 모으면 패턴 표가 됩니다(공통 캐소드, 1 = 켜짐).

숫자켜는 세그먼트dp g f e d c b a16진수
0a b c d e f0 0 1 1 1 1 1 10x3F
1b c0 0 0 0 0 1 1 00x06
2a b d e g0 1 0 1 1 0 1 10x5B
3a b c d g0 1 0 0 1 1 1 10x4F
4b c f g0 1 1 0 0 1 1 00x66
5a c d f g0 1 1 0 1 1 0 10x6D
6a c d e f g0 1 1 1 1 1 0 10x7D
7a b c0 0 0 0 0 1 1 10x07
8모두0 1 1 1 1 1 1 10x7F
9a b c d f g0 1 1 0 1 1 1 10x6F

공통 애노드라면 켜는 것이 LOW 이므로 패턴을 반전(~pattern)해서 내보내면 됩니다.

예제 1 — HAL 로 0~9 카운터#

시뮬레이터에서 열기FND 카운터 열기새 창l12-fnd
cCore/Src/main.c
/* USER CODE BEGIN 0 */
/* 공통 캐소드 FND 숫자 패턴: bit0=a ... bit6=g, bit7=dp (1 = 켜짐) */
const uint8_t FND_DIGITS[10] = {
  0x3F, 0x06, 0x5B, 0x4F, 0x66,   // 0 1 2 3 4
  0x6D, 0x7D, 0x07, 0x7F, 0x6F    // 5 6 7 8 9
};

/* n (0~9) 을 표시합니다. PC0~PC7 이 a~dp 이므로 i 번째 비트 = GPIO_PIN_i */
void fnd_show(uint8_t n)
{
  uint8_t pattern = FND_DIGITS[n % 10];
  for (int i = 0; i < 8; i++) {
    HAL_GPIO_WritePin(GPIOC, (uint16_t)(1 << i), ((pattern >> i) & 1) ? GPIO_PIN_SET : GPIO_PIN_RESET);
  }
}
/* USER CODE END 0 */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    fnd_show(digit);
    digit = (digit + 1) % 10;
    HAL_Delay(1000);
  }
  /* USER CODE END 3 */
  • (pattern >> i) & 1 은 패턴의 i 번째 비트를 꺼냅니다.
  • (uint16_t)(1 << i) 는 GPIO_PIN_i 와 같은 값입니다(GPIO_PIN_0 = 1, GPIO_PIN_1 = 2 …). 세그먼트가 PC0 부터 순서대로 있어서 가능한 방법입니다.
  • 핀 8개를 한 번에 하나씩 바꾸므로 아주 짧은 순간 "반쯤 바뀐" 숫자가 존재합니다. 눈에는 안 보이지만, 멀티플렉싱(과제)에서는 잔상이 될 수 있습니다.

예제 2 — BSRR 로 한 번에 쓰기 + 버튼 카운터#

BSRR 은 상위 16비트(리셋)와 하위 16비트(셋)를 한 번의 쓰기로 처리합니다. 같은 핀의 셋·리셋 비트가 모두 1이면 셋이 우선하므로, "PC0~PC7 모두 리셋 + 패턴 비트만 셋" 을 한 번에 쓰면 8개 세그먼트가 동시에 바뀝니다. 다른 핀(PC8~PC15)에는 영향이 없습니다.

시뮬레이터에서 열기버튼 카운터 (BSRR) 열기새 창l12-fnd-bsrr
cCore/Src/main.c
/* USER CODE BEGIN 0 */
/* 공통 캐소드 FND 숫자 패턴: bit0=a ... bit6=g, bit7=dp (1 = 켜짐) */
const uint8_t FND_DIGITS[10] = {
  0x3F, 0x06, 0x5B, 0x4F, 0x66,   // 0 1 2 3 4
  0x6D, 0x7D, 0x07, 0x7F, 0x6F    // 5 6 7 8 9
};

/* 상위 16비트(리셋)로 PC0~PC7 을 모두 끄고, 하위 16비트(셋)로 필요한 세그먼트만 켭니다.
   같은 비트에 셋·리셋이 함께 1 이면 셋이 우선하므로 한 번의 쓰기로 끝납니다. */
void fnd_show(uint8_t n)
{
  GPIOC->BSRR = 0x00FF0000 | FND_DIGITS[n % 10];
}
/* USER CODE END 0 */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    fnd_show(digit);
    HAL_Delay(20);
  }
  /* USER CODE END 3 */

/* USER CODE BEGIN 4 */
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
  if (GPIO_Pin == B1_Pin && HAL_GetTick() - last_press > 200) {
    last_press = HAL_GetTick();
    digit = (digit + 1) % 10;
  }
}
/* USER CODE END 4 */
방식코드동시성다른 핀 영향
HAL_GPIO_WritePin × 8for 반복한 핀씩 차례로없음
ODR 읽고 쓰기GPIOC->ODR = (GPIOC->ODR & 0xFF00) | pattern;동시읽기와 쓰기 사이 인터럽트가 PC8~15 를 바꾸면 덮어씀
**BSRR 한 번**GPIOC->BSRR = 0x00FF0000 | pattern;동시없음 (원자적)
실습

  2. 16진수 A~F 패턴을 추가해 0~F 카운터로 만드세요. (A=0x77, b=0x7C, C=0x39, d=0x5E, E=0x79, F=0x71)
  3. 짝수일 때만 소수점(dp)을 켜 보세요. 패턴에 어떤 비트를 OR 하면 되나요?

자주 나는 오류와 해결#

증상원인해결
숫자가 반전되어 보임(꺼질 곳이 켜짐)공통 애노드인데 캐소드용 패턴 사용~pattern 으로 반전, 공통 핀을 전원 쪽에
모양이 이상함 (예: 1 이 7 처럼)세그먼트 배선 순서가 표와 다름핀 ↔ 세그먼트 표대로 다시 연결하거나 패턴 표 수정
켜진 세그먼트가 많을수록 어두워짐공통 핀에만 저항 하나세그먼트마다 저항
다른 기능 핀까지 바뀜GPIOC->ODR = pattern; 으로 상위 비트까지 0 으로 씀BSRR 사용 또는 마스크
아무 세그먼트도 안 켜짐(실물)FND 핀 배치를 잘못 봄(제품마다 다름)데이터시트 핀맵, 멀티미터 다이오드 모드로 확인

과제#

  1. 2자리 멀티플렉싱: FND 두 개의 세그먼트 선을 공유하고, 각 공통 핀을 트랜지스터로 번갈아 켜서 00~99 를 표시하세요. 자리 전환은 TIM 인터럽트(L07, 2~5 ms 주기)로 합니다.
  2. 가변저항(L09) 값을 0~9 로 나눠 FND 에 표시하세요.
  3. 예제 2의 HAL_Delay(20) 루프 대신, 값이 바뀔 때만 fnd_show() 를 부르도록 바꾸세요.
