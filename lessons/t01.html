T01STM32 제품군 총람

ST 와 STM32 의 역사, F0 부터 U5·WB·C0 까지 제품군 표, STM32F411RET6 이름 해독 규칙, 핀 수·패키지, Nucleo·Discovery·Eval 보드 체계와 제품군 고르는 기준을 정리합니다.

시뮬레이터에서 실습HAL 레퍼런스

학습 목표#

  • ST 가 어떤 회사이고 STM32 가 어떤 흐름으로 만들어져 왔는지 한 문단으로 설명할 수 있습니다.
  • F0 · F1 · F2 · F3 · F4 · F7 · G0 · G4 · H5 · H7 · L0 · L1 · L4 · L5 · U5 · WB · WL · C0 제품군을 코어 · 최대 클럭 · 플래시 · 특징 · 용도 로 구분할 수 있습니다.
  • STM32F411RET6 같은 칩 이름을 자리별로 해독하고, 반대로 "64핀 · 512 KB · LQFP" 라는 요구에서 이름을 조립할 수 있습니다.
  • 핀 수와 패키지(LQFP · UFQFPN · BGA · WLCSP)가 회로 설계와 납땜에 어떤 영향을 주는지 압니다.
  • Nucleo · Discovery · Eval 보드 체계의 차이를 알고, 목적에 맞는 제품군과 보드를 고르는 기준을 세울 수 있습니다.
이 레슨의 위치

PART 0 은 손을 움직이기 전에 STM32 의 구조를 이해하는 이론 트랙입니다. 실습 위주로 빨리 가고 싶다면 L01 로 건너뛰어도 됩니다. PART 0 의 각 레슨은 실습 레슨에서 "왜 그렇게 되는가" 를 설명해야 할 때 돌아와 읽는 참고서로도 쓸 수 있습니다.

ST 와 STM32 의 역사#

STMicroelectronics(ST)는 1987년 이탈리아의 SGS Microelettronica 와 프랑스의 Thomson Semiconducteurs 가 합쳐져 만들어진 유럽 반도체 회사입니다. 본사는 스위스 제네바에 있고, MCU 외에도 전력 반도체, 센서(MEMS 가속도계·자이로), 자동차용 반도체를 만듭니다.

STM32 는 2007년 STM32F1(Cortex-M3) 으로 시작했습니다. 이전까지 ST 는 주로 자체 8비트 코어(ST7, STM8)와 ARM7/ARM9 기반 STR7 · STR9 를 썼는데, Arm 이 MCU 전용으로 설계한 Cortex-M 코어를 라이선스해 32비트 MCU 를 만들면서 컴파일러·디버거·RTOS 같은 생태계를 통째로 가져올 수 있게 되었습니다. 그 뒤 흐름은 대략 다음과 같습니다.

시기출시의미
2007F1 (M3)첫 STM32. 지금도 BluePill(F103C8) 로 가장 많이 팔리는 라인
2010~2011F2, F4 (M3 / M4F), L1고성능 라인과 첫 저전력 라인. F4 는 FPU·DSP 명령을 얹어 교육·산업 표준이 됨
2012~2014F0 (M0), F3 (M4F 아날로그), L0 (M0+), F7 (M7)저가형과 고성능 양 끝으로 확장
2015~2017L4, L4+, H7 (M7 400 MHz, 이후 개정판 480 MHz)초저전력과 초고성능
2018~2020G0, G4, WB(BLE), L5 (M33 TrustZone), WL(LoRa)무선과 보안(Armv8-M) 세대

같은 시기에 도구도 바뀌었습니다. 초기에는 Standard Peripheral Library(SPL) 를 썼고, 2014년경부터 STM32Cube(HAL + CubeMX)가 표준이 되었습니다. 인터넷에서 찾은 오래된 예제가 RCC_APB2PeriphClockCmd(...) 같은 함수를 쓰면 SPL 코드이고, HAL_GPIO_WritePin(...) 이면 HAL 코드입니다. 두 코드는 섞어 쓸 수 없습니다.

MPU 도 있습니다

STM32MP1 · MP2 는 Cortex-A 코어를 가진 마이크로프로세서(MPU) 로 리눅스를 돌립니다. 이름은 비슷하지만 이 강좌에서 다루는 STM32 MCU 와는 개발 방식이 전혀 다릅니다. 2024년 발표된 STM32N6 (Cortex-M55 + NPU) 는 MCU 이지만 AI 가속에 특화되어 있어 입문용은 아닙니다.

표를 읽는 요령입니다.

  • 코어가 성능 등급입니다. M0/M0+ < M3 < M4F < M7 순서이고, M33 은 M4 급 성능에 보안(TrustZone)을 더한 것입니다. 코어의 차이는 T02 에서 다룹니다.
  • F/G 는 범용, L/U 는 저전력, H 는 고성능, W 는 무선, C 는 초저가입니다.
  • 세대가 새로울수록(G > F, U > L, H5 > H7 의 일부 기능) 같은 가격에서 기능이 많고 소비 전력이 낮지만, 인터넷 자료는 오래된 제품군(F1, F4)이 압도적으로 많습니다.
F411 이 이 강좌의 기준인 이유

STM32F411 은 Cortex-M4F 100 MHz, 플래시 512 KB, SRAM 128 KB 를 가진 F4 의 "효율형" 라인입니다. FPU 와 DSP 명령이 있어 부동소수점 계산이 편하고, NUCLEO-F411RE 보드가 저렴하며, 레퍼런스 매뉴얼 RM0383 이 F4 중에서 가장 얇아(주변장치가 적어) 읽기 좋습니다. F1(F103) 은 자료가 가장 많지만 FPU 가 없고 GPIO 레지스터 구조가 다른(CRL/CRH) 옛 설계라, 강좌는 F411 을 기준으로 하고 F103 과의 차이를 그때그때 짚습니다.

이름 해독 규칙#

칩 이름은 STM32 + 제품 종류 + 시리즈·라인 + 핀 수 + 플래시 + 패키지 + 온도 순서입니다. 자리별 코드는 다음과 같습니다.

핀 수와 패키지가 설계에 미치는 영향#

같은 F411 이라도 패키지에 따라 실제로 쓸 수 있는 핀이 다릅니다. DS10314 의 F411 패키지 표를 예로 들면 다음과 같습니다.

패키지핀GPIO 수몸체 크기손 납땜
UFQFPN4848367 × 7 mm어려움 (바닥 패드)
WLCSP494936약 3.0 × 3.2 mm (2.999 × 3.185)불가
LQFP64645010 × 10 mm가능 (Nucleo-64)
LQFP100 / UFBGA1001008114 × 14 / 7 × 7 mmLQFP 만 가능

F411 에는 LQFP48 패키지가 없어 48핀 제품은 UFQFPN48(...U6, BlackPill 의 F411CEU6) 뿐입니다. BluePill 의 F103C8T6 은 LQFP48 입니다.

  • LQFP 는 취미·교육·소량 생산에서 가장 편합니다. 0.5 mm 피치는 플럭스와 얇은 인두로 손 납땜이 됩니다.
  • QFN 은 리드가 없어 면적이 작고 기생 인덕턴스가 낮지만, 바닥의 노출 패드를 납땜하려면 리플로(오븐·핫플레이트)가 필요합니다.
  • BGA 는 핀이 100개를 넘을 때 면적을 줄이지만 4층 이상의 PCB 와 X-ray 검사가 필요해 취미 수준에서는 쓰지 않습니다.
  • 핀이 늘어나면 전원 핀 쌍(VDD/VSS) 도 늘어납니다. LQFP64 F411 은 VDD 4개 + VDDA + VBAT 가 있고, 모든 VDD 에 0.1 µF 디커플링 커패시터를 붙여야 합니다. 이 내용은 T05 에서 다시 봅니다.

Nucleo-6464핀아두이노 Uno 호환 + 모포 76핀이 강좌의 기준 (F103RB, F411RE, L476RG)
Nucleo-144144핀Uno 호환 + ST Zio + 모포이더넷·USB 커넥터 있는 모델 많음 (F429ZI, H743ZI)

Nucleo-64 의 ST-Link 부분은 분리선(V 자 홈) 을 따라 잘라 낼 수 있고, 잘라 낸 ST-Link 로 다른 보드(BluePill 등)를 프로그래밍할 수도 있습니다. Nucleo-64 의 회로도 · 핀 배치 · 솔더 브리지 설정은 ST 사용자 매뉴얼 UM1724 에 있습니다. 예를 들어 LD2 = PA5, B1 = PC13, USART2 = PA2/PA3 이 ST-Link 가상 COM 포트로 이어진 것도 UM1724 에 적혀 있습니다.

비공식 보드

BluePill(STM32F103C8T6), BlackPill(STM32F411CEU6 · F401CCU6) 은 중국산 저가 보드입니다. ST-Link 가 없어 별도 프로그래머가 필요하고, BluePill 은 USB D+ 풀업 저항 값이 잘못된 개체가 많습니다(10 kΩ, 규격은 1.5 kΩ). BlackPill F411 은 이 강좌의 F411RE 와 같은 라인이라 코드가 거의 그대로 돌아갑니다 (LED 는 PC13, 버튼 PA0).

어떤 제품군을 고를까#

처음에는 아래 순서로 생각하면 됩니다.

  1. 배우는 중이면 F4(F411/F401) 또는 F1(F103). 자료가 가장 많고, 이 강좌의 시뮬레이터가 지원합니다. 둘 중에서는 FPU 가 있고 레지스터 구조가 최신 제품군과 같은 F4 가 낫습니다.
  2. 배터리로 오래 동작해야 하면 L4 / U5 / L0. 소비 전력이 µA/MHz 단위로 표기되며, Stop 모드 전류가 수 µA 수준입니다.
  3. 모터·전원 제어면 G4 (또는 F3). 고해상도 타이머와 아날로그 블록이 내장되어 있습니다.
  4. LCD GUI · 영상 · 고속 연산이면 H7 / F7. 캐시와 큰 SRAM 이 필요합니다.
  5. BLE 가 필요하면 WB, LoRa 면 WL. 별도 무선 칩 없이 하나로 끝납니다.
  6. 원가가 가장 중요하면 C0 / G0. 8비트 MCU 가격에 32비트 성능을 얻습니다.
  7. 보안(TrustZone, 보안 부트)이 요건이면 M33 계열(L5, U5, H5).

여기에 더해 실제 제품 설계에서는 다음을 봅니다.

  • 주변장치 목록: USB · CAN · 이더넷 · ADC 채널 수 · 타이머 수 · 필요한 통신 포트 수. F411 은 CAN 이 없고 ADC 가 1개입니다.
  • 핀 수와 패키지: 필요한 GPIO 수, 손 납땜 여부.
  • 메모리: 플래시(코드 + 상수)와 SRAM(변수 + 스택 + 버퍼). RTOS 나 그래픽 라이브러리를 쓰면 SRAM 이 금방 부족합니다.
  • 수급과 수명: ST 의 "longevity commitment" 는 산업용 제품군을 10년 이상 공급합니다. 후속 제품군이 있는 오래된 라인(F2 → F4, L1 → L4)은 새 설계에 권장되지 않는 경우가 많으니, 제품 페이지의 상태(Active · NRND)를 확인합니다.
  • 가격: 1,000개 기준 단가는 ST 웹사이트 제품 페이지에 표시됩니다.

시뮬레이터로 제품군 비교하기#

이 강좌의 시뮬레이터는 MCU 를 먼저 고르고, 보드는 선택하는 구조입니다. 지원하는 MCU 는 다음 9종입니다.

제품군MCU코어 · 최대 클럭보드 프리셋
F0STM32F030R8Cortex-M0 · 48 MHzNUCLEO-F030R8
F1STM32F103C8 / STM32F103RBCortex-M3 · 72 MHzBlue Pill / NUCLEO-F103RB
F4STM32F401RE / F411RE / F446RECortex-M4F · 84 / 100 / 180 MHzNUCLEO-F401RE / F411RE / F446RE
F4STM32F407VG (100핀)Cortex-M4F · 168 MHzSTM32F4DISCOVERY
G0STM32G071RBCortex-M0+ · 64 MHzNUCLEO-G071RB
L4STM32L476RGCortex-M4F · 80 MHzNUCLEO-L476RG

같은 HAL 코드라도 제품군에 따라 달라지는 부분이 있습니다. 아래 예제로 직접 확인해 보세요.

  • G0 의 EXTI 콜백 — F1·F4·L4 는 HAL_GPIO_EXTI_Callback() 하나지만, G0 는 HAL_GPIO_EXTI_Rising_Callback() / HAL_GPIO_EXTI_Falling_Callback() 으로 나뉩니다. 인터럽트 이름도 EXTI4_15_IRQn 처럼 묶입니다.
시뮬레이터에서 열기G0 — 에지별 EXTI 콜백새 창mcu-g0-blink
  • L4 의 ADC 채널 번호와 보정 — 같은 PA0 핀이 F4 에서는 ADC_CHANNEL_0, L4 에서는 ADC_CHANNEL_5 입니다. L4 는 변환 전에 HAL_ADCEx_Calibration_Start() 도 부릅니다.
시뮬레이터에서 열기L4 — 가변저항 ADC새 창mcu-l4-adc
  • F0 에는 TIM2 가 없음 — 작은 제품군일수록 타이머·UART 개수가 적습니다. F030 은 TIM3 로 PWM 을 만듭니다. 이 예제는 보드 없이 MCU 만 놓고 LED 를 직접 배선합니다.
시뮬레이터에서 열기F030 맨 칩 — PWM 페이드새 창mcu-f030-pwm
  • 100핀 F407 과 Discovery 보드 — 핀이 많아 GPIOD·GPIOE 포트가 생기고, 보드 LED 4개가 PD12–PD15 에 있습니다. 사용자 버튼은 누르면 HIGH 입니다.
시뮬레이터에서 열기F407 Discovery — LED 회전새 창mcu-f407-disco
  • Blue Pill 처럼 VCP 가 없는 보드 — ST-Link 가상 COM 포트가 없으면 USB-UART 모듈을 USART1(PA9/PA10)에 따로 연결합니다.
시뮬레이터에서 열기F103C8 맨 칩 — 버튼·LED·USART1새 창mcu-f103-bare
MCU 바꾸기

시뮬레이터 오른쪽 Properties 의 MCU 목록에서 칩을 바꾸면 SystemClock_Config()(PLL·Flash 대기 상태), ADC 초기화, EXTI 인터럽트 이름이 그 제품군에 맞게 다시 생성됩니다. 직접 추가한 장치·배선과 USER CODE 는 남으므로, 같은 프로그램이 여러 칩에서 어떻게 달라지는지 비교할 수 있습니다.

자주 나는 오류와 해결#

증상원인해결
인터넷 예제가 컴파일되지 않고 RCC_APB2PeriphClockCmd 같은 함수가 없다고 함옛 SPL(Standard Peripheral Library) 코드HAL 예제로 바꾸거나 함수 대응표를 보고 이식. SPL 과 HAL 은 섞어 쓸 수 없음
CubeMX 에서 원하는 칩을 찾을 수 없음칩 이름 오타(O 와 0, I 와 1), 패키지 코드 차이데이터시트 Ordering information 과 대조. CubeMX 는 패키지까지 정확히 골라야 핀 그림이 맞음
코드는 같은데 보드가 다르니 LED 가 반대로 동작보드마다 LED 극성·핀이 다름 (Nucleo LD2 = PA5 active-high, BluePill PC13 active-low)보드 회로도(UM1724 등)를 먼저 확인
SRAM 이 모자라 링크 오류 region RAM overflowed이름에는 SRAM 크기가 없어서 넉넉하다고 착각데이터시트에서 SRAM 확인, 버퍼 줄이기, 더 큰 라인 선택
BluePill 이 USB 장치로 인식되지 않음D+ 풀업 저항 값 오류(10 kΩ)1.5 kΩ 으로 교체하거나 Nucleo 사용
저가 보드의 칩이 STM32 가 아님 (CKS32, GD32 등)호환 칩디버거가 거부하거나 주변장치가 조금 다를 수 있음. 학습용으로는 ST 정품 Nucleo 권장

과제#

  1. 아래 다섯 칩의 이름을 해독해 표로 만드세요: STM32F030F4P6, STM32F103C8T6, STM32F407VGT6, STM32L476RGT6, STM32H743ZIT6.
  2. ST 웹사이트의 제품 선택기(Product selector)에서 "Cortex-M4, 플래시 256 KB 이상, USB, 48핀" 조건으로 검색해 후보 세 개를 적고, 각각의 이름을 해독하세요.
  3. 여러분이 만들고 싶은 장치(예: 온습도 로거, 미니 로봇, 스마트 플러그)를 하나 정하고 "어떤 제품군을 고를까" 의 기준으로 제품군과 보드를 골라 이유를 세 줄로 쓰세요.
  4. UM1724 에서 NUCLEO-F411RE 의 ST-Link 분리선과 솔더 브리지(SB) 표를 찾아, HSE 클럭이 어디에서 오는지 적으세요 (T04 예습).
