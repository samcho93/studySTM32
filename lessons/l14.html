L14스텝모터

28BYJ-48과 ULN2003으로 풀스텝·하프스텝 시퀀스를 구동하고, 스텝 수로 각도를 제어합니다.

선수 레슨: L03
시뮬레이터에서 실습

학습 목표#

  • 스텝모터가 코일에 전류를 넣는 순서만으로 정해진 각도씩 회전하는 원리를 이해합니다.
  • 28BYJ-48(5 V 유니폴라)과 ULN2003 드라이버 보드를 연결하고, 1상 · 2상(풀스텝) · 하프스텝 시퀀스를 표로 씁니다.
  • 스텝 수로 각도를 계산하고(풀스텝 2048 / 하프스텝 4096 스텝 = 1회전), 스텝 간격으로 속도를 정합니다.

스텝모터와 28BYJ-48#

스텝모터는 여러 코일(상)에 정해진 순서로 전류를 흘리면 그때마다 회전자가 한 칸(스텝)씩 끌려가며 도는 모터입니다. 엔코더 없이도 "몇 스텝 보냈는지" 로 위치를 알 수 있어 3D 프린터, 카메라 짐벌, 계량기 바늘 등에 쓰입니다.

28BYJ-48 은 교육용으로 가장 흔한 5 V 소형 스텝모터입니다.

항목값
종류유니폴라 4상, 5 V
내부 모터풀스텝 32 스텝 / 회전
기어비약 1 : 64 (정확히는 약 63.68)
출력축 1회전풀스텝 약 2048 스텝, 하프스텝 약 4096 스텝
최대 속도대략 10~15 rpm (풀스텝 간격 약 2 ms)

ULN2003 은 달링턴 트랜지스터 7개가 든 칩으로, MCU 의 약한 신호(IN1~IN4)를 받아 코일 전류를 GND 쪽으로 흘려 줍니다(역기전력 다이오드 내장). 드라이버 보드의 LED 4개가 지금 켜진 코일을 보여 줍니다.

연결#

STM32 핀라벨ULN2003 보드비트
PC0ST_IN1IN1bit0
PC1ST_IN2IN2bit1
PC2ST_IN3IN3bit2

구동 시퀀스#

IN1~IN4 를 bit0~bit3 으로 보고 한 스텝마다 켤 코일을 표로 만듭니다.

방식단계 수시퀀스 (IN4 IN3 IN2 IN1)특징
1상 (웨이브)40001 0010 0100 1000전류 적음, 토크 약함
2상 풀스텝40011 0110 1100 1001코일 2개씩 — 토크 강함 (예제 1)
하프스텝80001 0011 0010 0110 0100 1100 1000 10011상·2상을 번갈아 — 각도 절반, 부드러움 (예제 2)

표를 순서대로 진행하면 정방향, 거꾸로 진행하면 역방향입니다. 코드에서는 현재 위치 step_index 를 +1 또는 −1 하고 표 길이로 나머지를 취해 순환시킵니다: (step_index + dir + 4) % 4 (+4 는 음수가 되지 않게 하는 요령).

예제 1 — 풀스텝 1회전 왕복#

시뮬레이터에서 열기풀스텝 1회전 열기새 창l14-stepper
cCore/Src/main.c
/* USER CODE BEGIN PV */
int step_index = 0;          // 시퀀스 표의 현재 위치
/* USER CODE END PV */

/* USER CODE BEGIN 0 */
/* 2상 여자 풀스텝: 코일 두 개씩 차례로 (IN1..IN4 = bit0..bit3) */
const uint8_t FULL_SEQ[4] = {0x03, 0x06, 0x0C, 0x09};

/* p 의 bit0~bit3 을 IN1~IN4 에 출력합니다. */
void stepper_out(uint8_t p)
{
  HAL_GPIO_WritePin(ST_IN1_GPIO_Port, ST_IN1_Pin, (p & 0x01) ? GPIO_PIN_SET : GPIO_PIN_RESET);
  HAL_GPIO_WritePin(ST_IN2_GPIO_Port, ST_IN2_Pin, (p & 0x02) ? GPIO_PIN_SET : GPIO_PIN_RESET);
  HAL_GPIO_WritePin(ST_IN3_GPIO_Port, ST_IN3_Pin, (p & 0x04) ? GPIO_PIN_SET : GPIO_PIN_RESET);
  HAL_GPIO_WritePin(ST_IN4_GPIO_Port, ST_IN4_Pin, (p & 0x08) ? GPIO_PIN_SET : GPIO_PIN_RESET);
}

/* steps > 0 이면 정방향, < 0 이면 역방향. 한 스텝마다 delay_ms 쉽니다. */
void stepper_move(int steps, uint32_t delay_ms)
{
  int dir = (steps >= 0) ? 1 : -1;
  if (steps < 0) steps = -steps;
  for (int i = 0; i < steps; i++) {
    step_index = (step_index + dir + 4) % 4;
    stepper_out(FULL_SEQ[step_index]);
    HAL_Delay(delay_ms);
  }
  stepper_out(0);            // 멈추면 코일 전류를 끊어 발열을 줄입니다
}
/* USER CODE END 0 */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    stepper_move(2048, 2);     // 정방향 1회전 (약 4초)
    HAL_Delay(500);
    stepper_move(-2048, 2);    // 역방향 1회전
    HAL_Delay(500);
  }
  /* USER CODE END 3 */
  • stepper_out() 은 패턴의 비트 4개를 IN1~IN4 에 내보냅니다.
  • 스텝 간격 2 ms × 2048 스텝 ≈ 4.1 초에 1회전(약 15 rpm) — 28BYJ-48 의 한계 근처입니다. 더 빠르게 하면 스텝을 놓칩니다(탈조).
  • 움직임이 끝나면 stepper_out(0) 으로 코일 전류를 끕니다. 켜 둔 채로 두면 위치는 단단히 유지되지만(유지 토크) 모터와 드라이버가 뜨거워집니다.

예제 2 — 하프스텝으로 90° 씩#

하프스텝은 1회전이 4096 스텝이므로 90° = 1024 스텝 입니다. 스텝 간격은 절반인 1 ms 로 두어 같은 회전 속도를 냅니다.

시뮬레이터에서 열기하프스텝 90도 열기새 창l14-stepper-half
cCore/Src/main.c
/* USER CODE BEGIN 0 */
/* 하프스텝: 1상 -> 2상 -> 1상 ... 8단계 (IN1..IN4 = bit0..bit3) */
const uint8_t HALF_SEQ[8] = {0x01, 0x03, 0x02, 0x06, 0x04, 0x0C, 0x08, 0x09};

/* p 의 bit0~bit3 을 IN1~IN4 에 출력합니다. */
void stepper_out(uint8_t p)
{
  HAL_GPIO_WritePin(ST_IN1_GPIO_Port, ST_IN1_Pin, (p & 0x01) ? GPIO_PIN_SET : GPIO_PIN_RESET);
  HAL_GPIO_WritePin(ST_IN2_GPIO_Port, ST_IN2_Pin, (p & 0x02) ? GPIO_PIN_SET : GPIO_PIN_RESET);
  HAL_GPIO_WritePin(ST_IN3_GPIO_Port, ST_IN3_Pin, (p & 0x04) ? GPIO_PIN_SET : GPIO_PIN_RESET);
  HAL_GPIO_WritePin(ST_IN4_GPIO_Port, ST_IN4_Pin, (p & 0x08) ? GPIO_PIN_SET : GPIO_PIN_RESET);
}

void stepper_move_half(int steps, uint32_t delay_ms)
{
  int dir = (steps >= 0) ? 1 : -1;
  if (steps < 0) steps = -steps;
  for (int i = 0; i < steps; i++) {
    step_index = (step_index + dir + 8) % 8;
    stepper_out(HALF_SEQ[step_index]);
    HAL_Delay(delay_ms);
  }
  stepper_out(0);
}
/* USER CODE END 0 */

  /* USER CODE BEGIN WHILE */
  while (1)
  {
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
    for (int k = 0; k < 4; k++) {
      stepper_move_half(1024, 1);   // 90도 = 4096 / 4
      HAL_Delay(500);
    }
    stepper_move_half(-4096, 1);    // 한 바퀴 되돌아가기
    HAL_Delay(1000);
  }
  /* USER CODE END 3 */

스텝 수 = 각도 / 360 × 4096 　 (하프스텝) 　 1회전 시간 = 4096 × 스텝 간격

속도를 올리고 싶다면 가속을 쓰세요

스텝모터는 정지 상태에서 갑자기 빠른 속도로 출발하면 따라오지 못합니다. 처음 몇십 스텝은 간격을 길게(예: 4 ms) 시작해 목표 간격까지 줄여 가는 가감속을 넣으면 더 빠른 속도까지 안정적으로 돌 수 있습니다.

실습
  1. 예제 1의 시퀀스를 1상(웨이브) 으로 바꾸고 차이(토크·전류)를 설명하세요.
  2. stepper_move(512, 2) 는 몇 도 회전인가요? 시뮬레이터에서 확인하세요.
  3. 예제 1의 스텝 간격을 1 ms 로 줄이면 실물에서는 어떤 일이 생길 수 있는지 예측하세요.
스스로 확인
  • 하프스텝으로 45° 돌리려면 몇 스텝?
  • step_index = (step_index - 1 + 8) % 8; 는 어떤 동작인가요?

자주 나는 오류와 해결#

증상원인해결
떨기만 하고 돌지 않음코일 순서(IN 배선) 틀림, 스텝 간격이 너무 짧음IN1~IN4 순서 확인, 간격 2 ms 이상
한 방향으로만 돔역방향에서 인덱스가 음수가 됨(i + dir + 4) % 4 처럼 양수로 만들기
힘이 약하고 쉽게 멈춤전원 전압·전류 부족(USB 5 V 공유), 1상 구동별도 5 V, 2상 풀스텝
모터·드라이버가 뜨거움멈춘 동안에도 코일에 전류이동 뒤 stepper_out(0)
1회전이 정확히 한 바퀴가 아님기어비가 정확히 64 가 아님(63.68…)정밀 위치는 실측 보정 또는 다른 모터

과제#

  1. 가변저항(L09) 값으로 스텝 간격(2~20 ms)을 바꿔 속도 조절 기능을 만드세요.
  2. 시계 초침: 1초마다 6°(하프스텝 약 68 스텝)씩 움직이세요. 누적 오차를 줄이려면 어떻게 계산해야 할까요?
  3. 가감속을 넣은 stepper_move_accel(steps) 를 만들고, 가감속 없이 가능한 최대 속도와 비교하세요.
