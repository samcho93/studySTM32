STM32 HAL
인터랙티브 강좌

CubeMX로 핀을 설정하고, 생성된 코드의 USER CODE 구역에 HAL 코드를 쓰고, 브라우저 시뮬레이터에서 LED·버튼·LCD·모터 회로로 바로 실행해 봅니다. 같은 코드를 STM32CubeIDE에 붙여 넣으면 실물 Nucleo 보드에서도 그대로 동작합니다. STM32 제품군·코어·메모리·클럭을 이해하는 PART 0 부터 GPIO·UART·타이머·PWM·ADC·I2C·SPI, 모터 제어와 미니 프로젝트까지 총 24개 레슨.

커리큘럼

PART 0

STM32 이해하기

손을 움직이기 전에 STM32 가 무엇인지 알아봅니다. 제품군과 이름 규칙, Cortex-M 코어, 메모리 맵과 버스, 클럭·리셋, GPIO 회로, 인터럽트와 NVIC, 타이머, 통신 인터페이스의 원리를 데이터시트 숫자와 함께 정리합니다.

T01
STM32 제품군 총람
ST 와 STM32 의 역사, F0 부터 U5·WB·C0 까지 제품군 표, STM32F411RET6 이름 해독 규칙, 핀 수·패키지, Nucleo·Discovery·Eval 보드 체계와 제품군 고르는 기준을 정리합니다.
45분 · 입문HAL 레퍼런스
T02
Cortex-M 코어 구조
RISC·하버드·Thumb-2, 코어 레지스터(R0~R15, xPSR), 스레드·핸들러 모드와 특권 레벨, 함수 호출 규약, 예외 진입 스태킹, M0·M3·M4·M7·M33 의 차이와 CMSIS-Core 함수를 익힙니다.
55분 · 기초HAL 레퍼런스
T03
메모리 맵과 버스
4 GB 주소 공간 구획, F411 의 실제 주소, 부트 매핑, AHB·APB 버스 매트릭스와 클럭 게이팅, GPIO_TypeDef 구조체와 GPIOA 매크로, 비트밴딩, DMA, 링커 스크립트와 빌드 로그의 text·data·bss 를 해설합니다.
55분 · 기초시뮬레이터
T04
클럭과 리셋 시스템
HSI·HSE·LSI·LSE 와 PLL(M·N·P·Q) 계산, AHB·APB 프리스케일러와 타이머 ×2 규칙, 플래시 대기 상태, SysTick 과 HAL_Delay, MCO·CSS, 리셋 종류와 RCC->CSR, 저전력 모드를 정리합니다.
50분 · 기초시뮬레이터
T05
GPIO 내부 구조와 전기 특성
핀 한 개의 회로(슈미트 입력, 풀업·풀다운, 푸시풀·오픈드레인 드라이버, AF 멀티플렉서), MODER~AFR 레지스터와 F1 의 CRL·CRH, BSRR 의 원자성, 전기 특성과 시리즈 저항 계산, 외부 회로 연결을 다룹니다.
55분 · 기초시뮬레이터
T06
인터럽트·예외와 NVIC
벡터 테이블과 IRQHandler 이름 규칙, NVIC 우선순위(프리엠션·서브·그룹), 테일체이닝, EXTI 라인 매핑과 SYSCFG, HAL 인터럽트 흐름, ISR 작성 규칙, SysTick 우선순위 함정, 폴링·인터럽트·DMA 비교를 익힙니다.
55분 · 기초시뮬레이터
T07
타이머 구조
고급·범용·기본 타이머와 비트 폭, PSC·CNT·ARR 카운터 블록과 주기 공식, 프리로드·섀도 레지스터, 출력 비교와 PWM 모드, 입력 캡처, 인코더, 원샷, 데드타임, 마스터·슬레이브, 워치독과 RTC 를 정리합니다.
55분 · 기초시뮬레이터
T08
통신 인터페이스 원리
UART 프레임과 보레이트 오차, I2C 의 오픈드레인·주소·ACK·클럭 스트레칭, SPI 의 4 모드와 NSS, 세 인터페이스 비교표, CAN·USB·I2S·SDIO 개요, SWD·JTAG 디버그 인터페이스와 선택 기준을 익힙니다.
55분 · 기초시뮬레이터
PART 1

시작하기

STM32 시리즈와 개발 도구를 알아보고, 시뮬레이터에서 첫 프로젝트를 만든 뒤 GPIO 출력·입력과 외부 인터럽트를 익힙니다.

L01
STM32 시리즈와 개발 환경
Cortex-M 코어와 F0·F1·F4·L4·H7 제품군, CubeIDE·CubeMX, HAL·LL·레지스터의 차이, Nucleo와 BluePill 보드를 정리합니다.
40분 · 입문HAL 레퍼런스
L02
시뮬레이터 둘러보기와 첫 프로젝트
CubeMX 핀아웃 → Generate Code → USER CODE 구역 → Build → Run 흐름을 시뮬레이터에서 처음부터 끝까지 따라 합니다.
50분 · 입문시뮬레이터
L03
GPIO 출력 — LED
GPIO 출력 모드, HAL_GPIO_WritePin·TogglePin, 핀 라벨과 main.h 매크로, BSRR 레지스터 직접 쓰기까지 LED로 익힙니다.
60분 · 입문시뮬레이터HAL 레퍼런스
L04
GPIO 입력 — 스위치
풀업·풀다운과 active-low 버튼, 폴링으로 읽기, 에지 검출과 디바운스를 다룹니다.
60분 · 입문시뮬레이터HAL 레퍼런스
L05
외부 인터럽트 EXTI
폴링과 인터럽트의 차이, EXTI 라인과 NVIC, HAL_GPIO_EXTI_Callback과 volatile, 인터럽트 안 디바운스를 익힙니다.
60분 · 초급시뮬레이터HAL 레퍼런스
PART 2

통신·타이머·아날로그

UART와 printf로 보드와 대화하고, 타이머 인터럽트와 PWM으로 시간을 다루며, ADC로 아날로그 값을 읽습니다.

L06
UART와 printf
USART2(ST-Link VCP)로 문자를 주고받고, __io_putchar 리타깃으로 printf를 쓰며, 수신 인터럽트로 명령어를 처리합니다.
70분 · 초급시뮬레이터HAL 레퍼런스
L07
타이머 인터럽트
타이머 클럭·PSC·ARR 계산 공식을 84 MHz·72 MHz 예로 익히고, HAL_TIM_PeriodElapsedCallback으로 정확한 주기 작업을 만듭니다.
60분 · 초급시뮬레이터HAL 레퍼런스
L08
PWM — LED 밝기와 서보
PWM 주파수·듀티를 PSC·ARR·CCR로 정하고, LED 페이드와 50 Hz 서보 각도 제어를 구현합니다.
70분 · 초급시뮬레이터HAL 레퍼런스
L09
ADC — 가변저항·조도센서
12비트 ADC 폴링 변환으로 가변저항을 읽고, 여러 채널을 스캔 + DMA로 계속 받아 오는 방법을 익힙니다.
70분 · 중급시뮬레이터HAL 레퍼런스
PART 3

주변기기

I2C LCD, SPI 장치, 7세그먼트, DC 모터 드라이버, 스텝모터를 HAL로 직접 구동합니다.

L10
I2C와 LCD1602
I2C 주소와 HAL의 8비트 주소 규칙, PCF8574 4비트 LCD 프로토콜, 완성 드라이버와 I2C 스캐너를 만듭니다.
90분 · 중급시뮬레이터HAL 레퍼런스
L11
SPI 기초
SCK·MOSI·MISO·CS 네 선과 모드, CS를 GPIO로 제어하는 법, HAL_SPI_TransmitReceive로 장치 ID를 읽습니다.
60분 · 중급시뮬레이터HAL 레퍼런스
L12
7세그먼트 FND
공통 캐소드·애노드와 세그먼트 패턴 표를 만들고, HAL과 BSRR 레지스터 두 방식으로 숫자를 표시합니다.
50분 · 초급시뮬레이터
L13
DC 모터 드라이버
L298N의 IN1·IN2·ENA로 방향과 PWM 속도를 제어하고, 가변저항·버튼으로 속도와 방향을 바꿉니다.
70분 · 중급시뮬레이터
L14
스텝모터
28BYJ-48과 ULN2003으로 풀스텝·하프스텝 시퀀스를 구동하고, 스텝 수로 각도를 제어합니다.
60분 · 중급시뮬레이터
PART 4

프로젝트

배운 것을 모아 스마트 선풍기를 만들고, 같은 코드를 STM32CubeIDE와 실물 보드로 옮깁니다.

L15
미니 프로젝트: 스마트 선풍기
가변저항 → PWM 모터 속도, 버튼 모드 전환, LCD 표시, UART 로그를 하나의 프로그램으로 묶습니다.
120분 · 중급시뮬레이터HAL 레퍼런스
L16
실물 보드로 옮기기
STM32CubeIDE 설치, .ioc 설정, 빌드와 ST-Link 플래시·디버그, 시뮬레이터와 실물의 차이와 안전한 배선을 정리합니다.
90분 · 중급시뮬레이터HAL 레퍼런스

STM32, STM32CubeMX, STM32CubeIDE, Nucleo 는 STMicroelectronics 의 상표입니다. 이 사이트는 교육용 비공식 자료이며, 시뮬레이터는 실제 MCU 의 동작을 단순화해 흉내 냅니다. 실물 보드 배선·전원은 L16 의 안전 수칙을 꼭 지키세요.
