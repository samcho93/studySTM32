## 학습 목표

- SPI 의 네 신호(SCK · MOSI · MISO · CS)와 전이중(full-duplex) 통신, 모드 0~3(CPOL/CPHA)을 설명합니다.
- CS 를 **GPIO 출력으로 직접 제어**하는 방식(Software NSS)을 이해하고 올바른 순서로 씁니다.
- `HAL_SPI_TransmitReceive` 로 명령을 보내며 동시에 응답을 받고, `Transmit` + `Receive` 로 나눠 쓰는 방법과 비교합니다.
- 핀 충돌(SPI1 SCK 와 LD2 가 같은 `PA5`)을 알아보고 다른 SPI 로 옮길 수 있습니다.

## SPI 기초

SPI 는 마스터가 만드는 클럭(SCK)에 맞춰 **보내는 선(MOSI)과 받는 선(MISO)이 동시에** 1비트씩 움직이는 동기식 직렬 통신입니다.
I2C 보다 선이 많지만 훨씬 빠르고(수 ~ 수십 MHz) 프로토콜이 단순해서 플래시 메모리, 디스플레이, ADC, 무선 모듈 등에 쓰입니다.

| 신호 | 방향 | 역할 |
|---|---|---|
| **SCK** | 마스터 → 장치 | 클럭 |
| **MOSI** | 마스터 → 장치 | Master Out, Slave In (보내는 데이터) |
| **MISO** | 장치 → 마스터 | Master In, Slave Out (받는 데이터) |
| **CS** (NSS) | 마스터 → 장치 | Chip Select, **LOW 일 때 그 장치가 선택됨**. 장치마다 하나씩 |

핵심은 **"보내는 만큼 받는다"** 입니다. 8클럭 동안 1바이트를 내보내면 같은 8클럭 동안 1바이트가 들어옵니다.
그래서 읽기만 하고 싶을 때도 마스터는 의미 없는 **더미 바이트**(0x00 또는 0xFF)를 보내 클럭을 만들어야 합니다.

### 모드 (CPOL · CPHA)

| 모드 | CPOL (쉴 때 SCK) | CPHA (샘플링 에지) | CubeMX |
|---|---|---|---|
| 0 | LOW | 첫 번째 에지(상승) | Clock Polarity Low, Clock Phase 1 Edge |
| 1 | LOW | 두 번째 에지(하강) | Low, 2 Edge |
| 2 | HIGH | 첫 번째 에지(하강) | High, 1 Edge |
| 3 | HIGH | 두 번째 에지(상승) | High, 2 Edge |

장치 데이터시트에 적힌 모드와 맞춰야 합니다. 대부분의 플래시 메모리·센서는 **모드 0**(또는 0과 3 모두 지원)입니다.

## 핀 선택: SPI1 대신 SPI2

NUCLEO-F411RE 에서 SPI1 의 기본 핀은 `PA5`(SCK) / `PA6`(MISO) / `PA7`(MOSI) 입니다. 그런데 **`PA5` 는 LD2** 와 연결되어 있어,
SPI1 을 쓰면 클럭이 나갈 때마다 LD2 가 깜빡이고 LD2 를 GPIO 로 쓸 수 없습니다. 이 강좌는 **SPI2** 를 씁니다.

@table[pinmap]
| 핀 | 신호 | Nucleo 헤더 (모포) | 연결 |
|---|---|---|---|
| `PB13` | `SPI2_SCK` | CN10-30 | 장치 SCK (CLK) |
| `PB15` | `SPI2_MOSI` | CN10-26 | 장치 DI (SI, SDI) |
| `PB14` | `SPI2_MISO` | CN10-28 | 장치 DO (SO, SDO) |
| `PB12` | `GPIO_Output`, 라벨 `FLASH_CS`, **초기 레벨 High** | CN10-16 | 장치 CS |

### CubeMX 설정

1. **Connectivity → SPI2 → Mode: Full-Duplex Master**, **Hardware NSS Signal: Disable** (CS 는 GPIO 로 직접)
2. Parameter Settings: Data Size 8 Bits, First Bit MSB First, **Prescaler 16** (APB1 42 MHz / 16 = 2.625 MHz), CPOL Low, CPHA 1 Edge
3. `PB12` 를 `GPIO_Output` 으로, **GPIO output level: High** — 시작하자마자 장치가 선택되지 않도록

## 예제 1 — 장치 ID 읽기 (TransmitReceive)

W25Q 계열 SPI 플래시는 명령 `0x9F`(Read JEDEC ID)를 받으면 제조사·메모리 종류·용량 3바이트를 돌려줍니다.
예제 회로의 범용 SPI 장치 노드는 `reply` 속성(`FF EF 40 18`)의 바이트를 순서대로 돌려주도록 설정되어, W25Q128 처럼 동작합니다.

@sim[l11-spi-id] SPI ID 읽기 열기

@code[l11-spi-id] pv,loop

```text
MOSI(보냄) :  9F    00    00    00
MISO(받음) :  FF    EF    40    18      ← rx[0] 은 명령을 보내는 동안 들어온 의미 없는 값
```

- `tx` 4바이트를 보내는 동안 `rx` 4바이트가 채워집니다. 명령을 보내는 첫 바이트 동안 장치는 아직 할 말이 없으므로 `rx[0]` 은 버리고 `rx[1]~rx[3]` 을 씁니다.
- **CS 를 LOW 로 내리고 → 통신하고 → HIGH 로 올리는** 순서가 한 "명령" 입니다. 많은 장치가 CS 가 올라가는 순간 명령을 끝냅니다.

## 자주 나는 오류와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 받은 값이 모두 `FF` | MISO 미연결, CS 가 LOW 로 내려가지 않음, 장치 전원 없음 | 배선, CS 코드, 전원 확인 |
| 받은 값이 모두 `00` | MISO 가 GND 로 붙음, 장치가 리셋 상태 | 배선 확인 |
| 값이 한 비트씩 밀려 있음 (예: `EF` 대신 `77` / `DE`) | SPI 모드(CPOL/CPHA) 불일치 | 데이터시트의 모드로 맞추기 |
| 전원 켜자마자 장치가 이상 동작 | CS 초기 레벨이 Low | CubeMX 에서 CS 핀 초기 레벨 High |
| SPI1 을 켰더니 LD2 가 깜빡임 | `PA5` 공유 | SPI2 사용 또는 SPI1 을 `PB3`/`PB4`/`PB5` 로 재배치 |
| 속도를 올렸더니 가끔 틀린 값 | 긴 점퍼선, 장치 최대 클럭 초과 | Prescaler 를 키워 속도 낮추기, 배선 짧게 |
