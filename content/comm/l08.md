## 학습 목표

- PWM 의 **주파수**와 **듀티비**를 설명하고, 타이머의 PSC · ARR · CCR 로 두 값을 정합니다.
- CubeMX 에서 타이머 채널을 **PWM Generation** 으로 설정하고 `HAL_TIM_PWM_Start` · `__HAL_TIM_SET_COMPARE` 로 출력합니다.
- LED 밝기를 부드럽게 바꾸고(페이드), 50 Hz 서보 모터의 각도를 펄스 폭으로 제어합니다.

## PWM 이란

PWM(Pulse Width Modulation)은 디지털 핀을 아주 빠르게 켰다 껐다 하면서 **켜져 있는 시간의 비율(듀티비)** 을 바꾸는 방법입니다.
LED 는 사람 눈이 따라가지 못하는 속도(수백 Hz 이상)로 깜빡이면 평균 밝기로 보이고, 모터는 평균 전압에 해당하는 속도로 돕니다.

```text
듀티 25 %   ▔▔╲___________▔▔╲___________     평균 = 3.3 V × 0.25 ≈ 0.8 V
듀티 75 %   ▔▔▔▔▔▔▔▔╲_____▔▔▔▔▔▔▔▔╲_____     평균 ≈ 2.5 V
            |<─── 주기 T = 1 / f ───>|
```

## 타이머로 PWM 만들기

PWM 모드 1 에서 타이머 채널은 **CNT < CCR 인 동안 HIGH, 나머지 LOW** 를 출력합니다. 그래서

- **주파수** = 타이머 클럭 / ((PSC + 1) × (ARR + 1)) — L07 과 같은 공식
- **듀티비** = CCR / (ARR + 1) — CCR 은 CubeMX 의 *Pulse* 값, 코드에서는 `__HAL_TIM_SET_COMPARE` 로 바꿈

@table[regmap]
| 용도 | 타이머 클럭 | PSC | ARR | 주파수 | CCR 범위 |
|---|---|---|---|---|---|
| LED 밝기 | 84 MHz | 83 | 999 | 1 kHz | 0(꺼짐) ~ 999(거의 100 %) |
| 서보 (SG90) | 84 MHz | 83 | 19999 | 50 Hz (20 ms) | 500 ~ 2500 = 0.5 ~ 2.5 ms |
| DC 모터 (L13) | 84 MHz | 3 | 999 | 21 kHz | 0 ~ 999 |

PSC = 83 으로 두면 카운터 1틱이 **1 µs** 라서 서보처럼 "펄스 폭 몇 µs" 로 말하는 장치를 다루기 편합니다.
CCR 을 ARR+1 이상으로 두면 계속 HIGH(100 %), 0 이면 계속 LOW 입니다.

### 핀과 채널

타이머 채널은 정해진 핀으로만 나갑니다(대체 기능 AF). NUCLEO-F411RE 에서 자주 쓰는 조합입니다.

@table[pinmap]
| 핀 | 신호 | Nucleo 헤더 | 비고 |
|---|---|---|---|
| `PA0` | `TIM2_CH1` | A0 | 서보 예제 |
| `PA5` | `TIM2_CH1` | D13 | LD2 와 같은 핀 — 보드 LED 밝기 조절 가능 |
| `PA6` | `TIM3_CH1` | D12 | LED 페이드 예제 |
| `PA7` | `TIM3_CH2` | D11 | |
| `PB6` | `TIM4_CH1` | D10 | |

### CubeMX 설정 (TIM3 CH1, 1 kHz)

1. `PA6` 을 눌러 `TIM3_CH1` 선택
2. **TIM3 → Channel1: PWM Generation CH1**
3. Prescaler `83`, Counter Period `999`, PWM Generation Channel 1 → Mode *PWM mode 1*, **Pulse `0`**, Polarity High

@sim[l08-pwm-led] LED 페이드 열기

@code[l08-pwm-led] pv,u2,loop

- `HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1)` 을 빼먹으면 설정은 되어 있어도 **핀이 전혀 움직이지 않습니다.** 가장 흔한 실수입니다.
- 10 ms 마다 듀티를 10 씩 바꾸므로 0 → 999 까지 약 1초, 다시 0 까지 1초 걸립니다.
- 예제 회로에는 **로직 분석기** 노드(`ch0`)가 같은 핀에 연결되어 있어, 실습 결과 영역에서 파형의 폭이 변하는 것을 볼 수 있습니다.

:::tip 사람 눈은 밝기를 로그로 느낍니다
듀티를 일정하게 올려도 어두운 쪽에서 밝기 변화가 크고, 밝은 쪽에서는 거의 변화가 없어 보입니다.
자연스러운 페이드를 원하면 듀티를 제곱으로 바꾸는 **감마 보정**(예: `ccr = duty * duty / 999`)을 써 보세요.
:::

## 예제 2 — 서보 모터 스윕

취미용 서보(SG90 등)는 **20 ms(50 Hz) 마다 들어오는 펄스의 폭**으로 각도를 정합니다. 표준은 1 ms(0°) ~ 2 ms(180°) 이지만,
SG90 계열은 대략 0.5 ms ~ 2.5 ms 에서 0° ~ 180° 로 움직이는 경우가 많습니다. 제품마다 다르니 **양 끝은 조금씩 넓혀 가며 확인**하세요.

@table[pinmap]
| 핀 | 신호 | 서보 선 |
|---|---|---|
| `PA0` | `TIM2_CH1` (PSC 83, ARR 19999, Pulse 1500) | 신호(주황/노랑) |
| — | 5 V 전원 | 빨강 |
| — | GND (보드 GND 와 공통) | 갈색/검정 |

@sim[l08-servo] 서보 스윕 열기

@code[l08-servo] u0,u2,loop

`servo_write()` 는 각도를 `500 + 각도 × 2000 / 180` µs 로 바꿉니다. 먼저 `(uint32_t)angle * 2000` 을 계산한 뒤 나누어,
정수 나눗셈에서 정밀도를 잃지 않게 했습니다. 시뮬레이터의 서보 노드는 `minUs`/`maxUs` 속성(500/2500)으로 같은 대응을 합니다.

:::warn 서보 전원은 따로
서보는 움직이는 순간 수백 mA 를 끌어 씁니다. 실물에서 Nucleo 의 5V 핀으로 여러 개를 돌리면 전압이 떨어져 보드가 리셋될 수 있습니다.
**별도 5 V 전원**을 쓰고, 그 전원의 GND 를 보드 GND 와 **반드시 연결**하세요(신호의 기준점).
:::

## 자주 나는 오류와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 핀에 아무 신호도 없음 | `HAL_TIM_PWM_Start` 누락, 채널을 PWM Generation 으로 설정하지 않음 | 두 가지 모두 확인 |
| 다른 채널 번호를 써서 안 바뀜 | `TIM_CHANNEL_2` 인데 CH1 핀에 연결 | 핀아웃의 채널 번호와 코드 일치 |
| 밝기가 최대에서 더 안 올라감 / 항상 켜짐 | CCR > ARR | CCR 을 0 ~ ARR 범위로 제한 |
| 서보가 떨리거나 끝에서 윙 소리 | 펄스 폭이 기구 한계를 넘음, 전원 부족 | min/max µs 를 좁히기, 별도 전원 + 공통 GND |
| 서보가 전혀 안 움직임 | 주파수가 50 Hz 가 아님(ARR 을 999 로 둠), GND 미연결 | PSC 83 / ARR 19999, GND 공통 |
